## Your goal is to build a regression model that explains the variability of a penguin's body mass in grams.

### 1) Data Preparation  
Ensure that the data is properly loaded and that the variable types are suitable for analysis.

### 2) Initial Model  
Construct the first model using **linear regression**, incorporating all other variables from the dataset as predictors.

### 3) Linear Regression Model Specification  
Formulate the linear regression model as follows:  
\[
y = B_1X_1 + B_2X_2 + ... + B_nX_n + \varepsilon
\]  
Interpret the **Beta parameters** in terms of their impact on the response variable.

### 4) Model Interpretation  
Analyze the model parameters, including:  
- The **significance** of individual variables (**Pr(>|t|)**),  
- The **R-squared** value,  
- The **p-value** of the model.

### 5) Residual Analysis  
Create a **scatter plot** of the residuals.  
Research and determine whether the model exhibits **homoscedasticity** or **heteroscedasticity** using any method of your choice.

### 6) Model Prediction  
Make predictions for the following case:  
- **Chinstrap penguin**,  
- **Male**,  
- **Bill length**: 46 mm,  
- **Bill depth**: 21 mm,  
- **Flipper length**: 210 mm.

### 7) Build a Competitive Model  
Manually construct an **alternative regression model** with:  
- Any regression method of your choice,  
- Any parameters of your choice,  
- **R² ≥ 0.75**.

### 8) Model Comparison  
Compare the results of both models. Identify which model performs better for predictions and explain why.
